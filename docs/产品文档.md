## 一、产品概述

「RAG 企业级知识库问答系统」是一个基于 **LangChain** 框架构建的检索增强生成（RAG）问答系统。用户通过浏览器访问，针对电商平台售卖的商品进行问答。系统从知识库（以商品信息为主）中检索相关内容，结合大语言模型（LLM）生成准确、有据可查的回答，并在回答中展示所引用的知识库片段来源。

- **平台**：Web 应用（浏览器访问，无需客户端安装）
- **核心能力**：知识库管理 + RAG 检索增强问答
- **应用场景**：电商商品问答（商品参数、功能、规格、使用方法、售后政策等）
- **关键词**：LangChain、RAG、向量检索、多用户、会话管理

## 二、目标用户

| 用户类型 | 说明 |
| --- | --- |
| 普通用户 | 登录后在浏览器中对商品知识库进行问答，管理自己的独立会话 |
| 管理员（admin） | 除问答外，还负责知识库内容的上传、解析与管理维护 |

## 三、核心功能

### 1. 知识库管理（仅管理员）
- **知识库管理**：支持创建 / 删除多个知识库（如按品类划分：家电、数码、服饰等）
- **文档上传**：支持 PDF、Word(.docx)、TXT、Markdown、CSV 等常见格式
- **文档解析与入库**：自动完成「解析 → 分块（chunking）→ 向量化 → 写入向量库」
- **文档状态管理**：解析中 / 已入库 / 解析失败，支持失败重试
- **文档操作**：删除、重新解析、查看分块列表与内容
- **入库进度**：展示解析 / 向量化进度

### 2. 知识库问答（所有登录用户）
- **RAG 问答**：输入问题 → 检索知识库 → 结合 LLM 生成回答
- **引用展示**：回答中明确展示引用的知识库片段（来源文档名、片段内容、相关度分数）
- **流式输出**：回答以打字机效果实时输出
- **知识库选择**：可指定 / 切换要问答的知识库
- **多轮对话**：支持上下文连续追问（携带对话历史记忆）

### 3. 多用户、多会话管理
- **独立会话**：每个用户拥有自己的会话列表，互不干扰
- **会话管理**：新建、重命名、删除会话
- **会话持久化**：会话与消息记录落库保存，用户不同时间段登录均可找回历史对话

### 4. 用户管理
- **注册 / 登录 / 退出**
- **修改密码**
- **角色权限**：`admin`（管理员）可进行知识库管理 + 问答；普通用户仅可问答
- **初始账号**：管理员用户名 `admin`，初始密码 `123456`（首次登录后建议修改）

## 七、RAG 技术流程

**文档入库（离线异步）**：
上传文档 → 解析提取文本 → 文本分块（chunking）→ Embedding 向量化 → 写入向量数据库

**问答（在线）**：
用户提问 → 问题向量化 → 向量检索 Top-K 相关分块 →（可选）重排序 → 构造带上下文的 Prompt → LLM 生成回答 → 返回回答 + 引用片段

## 八、非功能需求 / 企业级性能优化

1. **检索性能**：向量索引（HNSW / IVF）加速近邻搜索，目标毫秒级响应
2. **混合检索**：向量检索 + 关键词（BM25）结合，提升召回率
3. **重排序（Rerank）**：对召回结果二次精排，提升准确率
4. **缓存**：相似问题结果缓存（Redis）命中后直接返回；Embedding 结果缓存
5. **异步化**：文档解析 / 向量化采用异步任务，避免阻塞请求
6. **流式输出**：LLM 输出流式返回，提升体验
7. **安全**：密码哈希存储、JWT / 会话认证、角色权限控制、SQL / 提示词注入防护、上传文件校验
8. **可观测性**：操作日志、问答记录、检索耗时统计
9. **限流与防滥用**：接口限流，防止恶意调用

## 九、技术方案

### 9.1 已确认决策（用户拍板）

| 决策 | 选择 | 说明 |
| --- | --- | --- |
| 大语言模型（LLM） | **DeepSeek API** | 便宜、中文强、无需 GPU，需 API Key |
| 向量数据库 | **Chroma** | 轻量、LangChain 原生、本地持久化 |
| 交付方式 | **GitHub 公开仓库 + 本机可运行** | 代码开源可见，克隆后本地一键启动 |

### 9.2 推荐方案（默认采用，如有异议可调整）

| 决策 | 推荐 | 理由 |
| --- | --- | --- |
| 后端框架 | Python 3.11 + FastAPI | LangChain Python 生态最成熟、异步性能好 |
| 前端框架 | React 18 + Ant Design 5 + Vite | 组件丰富、生态大 |
| Embedding 模型 | BGE（bge-m3，本地 sentence-transformers） | 中文效果好、免费离线；DeepSeek 无成熟 Embedding 需另配 |
| 关系数据库 | SQLAlchemy ORM + SQLite（可平滑换 PostgreSQL） | 本地零依赖即可运行，换库仅改配置 |
| 缓存 / 中间件 | Redis（可选，企业级优化） | 问答结果缓存、限流计数；本地可降级为内存实现 |
| 异步任务 | FastAPI BackgroundTasks | 轻量够用，文档解析 / 向量化不阻塞请求 |
| 部署 | 一键启动脚本 + 可选 Docker Compose | 兼顾本机直跑与一键编排 |

### 9.3 关键技术选型说明

- **LLM 接入**：DeepSeek 提供 OpenAI 兼容接口，LangChain 用 `ChatOpenAI`（base_url 指向 DeepSeek）即可接入，无需自研封装。
- **Embedding**：DeepSeek 无成熟 Embedding 接口，故采用本地 BGE 模型，避免二次付费、支持离线。
- **向量库**：Chroma 默认持久化到本地目录，重启不丢数据，适合单机部署。
