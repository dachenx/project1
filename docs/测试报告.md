## 三、覆盖了什么

- **认证安全（security）**：密码 bcrypt 哈希 round-trip、错误密码拒绝、随机盐（同明文两次哈希不同）、JWT 签发/解码 round-trip、payload 含 sub/role/exp、篡改 token 抛错。
- **缓存（cache）**：内存缓存 get/set、缓存未命中、TTL 过期、缓存 key 确定性（同问题同 key）与唯一性（不同问题/不同知识库不同 key）、Redis 不可达时自动降级内存。
- **RAG prompt 构造（rag）**：collection 命名（有/无 kb_id）、含/不含引用的 prompt 拼接、空引用显示「（无）」、多轮历史拼接、系统提示词含提示词注入防护规则。
- **文件校验（kb）**：PDF（`%PDF`）、docx（`PK`）魔数校验、文本含空字节拒绝、扩展名与内容不符抛 400。
- **数据模型（schemas）**：Pydantic 必填字段校验、`from_attributes` 反序列化、`TokenOut` 默认 `token_type="bearer"`。
